# 🍽️ DineOut - Restaurant Order Management Dashboard

A modern and intuitive restaurant order management system designed to streamline the order creation, tracking, and fulfillment process. This dashboard allows staff to manage food orders, monitor order status, and handle order history seamlessly — all from one user-friendly interface.

## 🚀 Features

- ✅ **Header** — Clean, responsive header for consistent branding.
- ✅ **Add / Remove Items** — Dynamically select or deselect menu items while creating an order.
- ✅ **Create Order** — Create and place new orders with selected items and customer name.
- ✅ **Order Summary** — Display real-time stats of total, pending, and delivered orders.
- ✅ **Order Reports** — View all order details including customer, items, amount, and status.
- ✅ **Deliver Order** — Mark any pending order as delivered with one click.
- ✅ **Delete Order** — Remove any unwanted or incorrect orders from the system.
- ✅ **Filter Orders** — Filter orders by status (e.g., delivered, pending).
- ✅ **Delete History** — Option to delete order history for maintenance or resetting data.
